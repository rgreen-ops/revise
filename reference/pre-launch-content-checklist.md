# Pre‑launch CONTENT checklist — fill these before go‑live

Everything below is content/settings the **team** needs to add or confirm on
**staging** before launch. Anything left blank just shows a placeholder or a
sensible default — nothing breaks — but for a polished launch, work through it.
Group by group. Tick as you go.

> How to edit: log into staging `wp-admin`. Most items say exactly where.

---

## 1. Site identity & company data
- [ ] **Logo** — Appearance → Editor → header (or Ricoman → Header & Menu).
- [ ] **Favicon / site icon** — Settings → General (or Appearance).
- [ ] **Company name, address, phone, email, opening hours** — Ricoman → Header &
      Menu / Footer settings (these feed the footer + the LocalBusiness schema).
- [ ] **Company registration no. / VAT** (footer/legal, if shown).
- [ ] **Social links** (LinkedIn, Instagram, etc.) — footer settings.
- [ ] **Footer columns / links** — Ricoman → Footer (check every link works).

## 2. Tracking & integrations
- [ ] **Google Analytics 4 / Google Tag Manager ID** — Ricoman → Tracking & Scripts.
- [ ] **Contact / enquiry recipient email** — confirm where enquiries are sent.
- [ ] **BIM request inbox** — defaults to lightingdesign@ricoman.com; confirm.
- [ ] **Newsletter / leads Google Sheet webhook** (if used) — lead‑capture settings.
- [ ] **Google Search Console** — verify the live domain (do at launch).
- [ ] **Cookie/consent banner** — confirm it's present and links to the policy.

## 3. Homepage
- [ ] **Brand film video** — re‑host locally + swap the URL in the "Home · Brand
      film" block (currently points at the old site).
- [ ] **Reach stats numbers** ("Home · Reach stats" pattern) — countries, projects.
- [ ] **Facts band** numbers ("Home · Facts band").
- [ ] **Partner logos** — replace the placeholder boxes with real logos
      ("Home · Partner logos").
- [ ] **Testimonials** — replace the sample quotes with real ones
      ("Home · Testimonials").
- [ ] **Featured product / projects** — confirm the linked items are right.

## 4. Products
- [ ] **Colour finishes (chips)** — check each product's "Colour finishes" box
      (names, swatches, main images). Migrated data is pre‑loaded; tidy as needed.
- [ ] **Product FAQs** — add FAQs to the key products ("Product FAQs" box).
- [ ] **Cut‑out sizes** — fill the `cut_out` column in the variant CSV for
      downlights (enables the cut‑out filter).
- [ ] **Configure families** — create the Estrella family (Products → Configure
      Families) + tag the member products (Opal, Wallwasher, louvres, etc.).
- [ ] **Downloads** — upload real datasheets / instructions / IES‑LDT / BIM files
      where missing.
- [ ] **Spot‑check spec/variant tables** on the main ranges.

## 5. Categories
- [ ] **Category images** (In‑situ + Studio) — Products → Categories → each term.
- [ ] **Category SEO copy** (intro + body/FAQ) — seeded for core ranges; review +
      add for the rest.
- [ ] **Display order** — set the order categories appear (menu, /products/, home).

## 6. News, Projects, Team
- [ ] **News** — publish the launch posts; set Topics + byline (Writer/role).
- [ ] **Projects** — confirm case studies; tag the **Sector** and **Consultant (SPC)**.
- [ ] **Team profiles** — add staff (name, photo, job title, email, phone, bio);
      tag them onto their news/projects.
- [ ] **Consultants (SPC)** — create each + assign to their projects.

## 7. SEO & redirects (launch‑critical)
- [ ] **Per‑page SEO titles/descriptions** — auto‑seeded; review the key pages.
- [ ] **301 redirect map** — compile the list of important **old URLs** and confirm
      each points to its new page (Ricoman → Links & Redirects). This is the big one
      for keeping Google rankings.
- [ ] **robots / sitemap** — confirm the sitemap lists the right pages.

## 8. Legal & policy pages
- [ ] **Privacy, Cookie, Terms, Email notice, Modern Slavery, Warranty** — confirm
      each has the correct, up‑to‑date wording.

## 9. Final visual pass
- [ ] Click every main menu + footer link.
- [ ] Check the site on a phone.
- [ ] Read the homepage, About, Contact and one of each template (product,
      category, news, project) as a customer would.

---
When this is done, staging is "content‑complete" and ready for the Friday launch.

# Launch‑day checklist (Friday AM) — ricoman.com

Work top to bottom. The same list is in **WP → Ricoman → 🚀 Go Live** as tick‑boxes
that save your progress. If anything fails, note what you saw and tell Claude — it's
fixable, and you have the pre‑launch backup as a safety net.

## 1. First (technical — Richard)
- [ ] Full backup of the LIVE site taken **before** the copy (rollback).
- [ ] Staging copied onto live via Plesk WordPress Toolkit (Copy Data).
- [ ] **https://ricoman.com** loads with a padlock (SSL valid).
- [ ] Settings → Reading → **"Discourage search engines" is UNTICKED**.
- [ ] Ricoman → 🚀 Go Live → **Run launch finalisation** (all checks green).

## 2. Pages look right
- [ ] Homepage: hero, images/video, all sections.
- [ ] Top menu / mega‑menu links work; footer links work.
- [ ] Products page + a few category pages (filters + sliders work).
- [ ] 3–4 product pages: gallery, colour chips, Configure table, downloads, FAQ.
- [ ] News list + an article (byline, topics). Projects list + a project.
- [ ] Team page + a staff profile (their projects/news show).
- [ ] About, Contact, Sustainability + feature pages (Casambi, etc.).
- [ ] Legal pages (Privacy, Terms, Cookies…) open.
- [ ] Search returns results; a made‑up URL shows the friendly 404.
- [ ] Spot‑check on a phone (menu, a product, the contact form).

## 3. Forms & functions work
- [ ] Contact / enquiry form → appears in **Ricoman → Leads** + email arrives.
- [ ] Newsletter signup works.
- [ ] Download gate: logged out, click a datasheet → popup → submit → file
      downloads + lead logged.
- [ ] BIM/Revit "request" logs a lead + emails lightingdesign@ricoman.com.
- [ ] Register + log in; "Add to My Project" + project‑pack ZIP work.
- [ ] Request a callback works. Flow Designer loads.

## 4. Old links redirect (301s) — SEO critical
- [ ] Test a sample of **old** URLs (product, category, news, project) → each
      lands on the right new page, not a 404.
- [ ] **Ricoman → Links & Redirects** — map loaded; add any missing.
- [ ] Watch the **404 log** for the first hours/days; redirect stragglers.
- [ ] robots.txt allows crawling; sitemap loads (/sitemap_index.xml).
- [ ] Submit the sitemap in **Google Search Console**; request homepage indexing.

## 5. SEO & analytics
- [ ] A product's source has a title + meta description (no "noindex").
- [ ] Analytics/GTM firing (real‑time shows your visit).
- [ ] One product URL passes Google's Rich Results test (Product/FAQ schema).

## 6. Sign‑off & watch
- [ ] All above ticked → tell the team it's live. 🎉
- [ ] First few days: watch Leads, the 404 log, and any error reports.
- [ ] From now on: content via Draft → Preview → Publish; code via 🚀 Push to
      Live. **Never copy staging over live again** (it would wipe live leads).

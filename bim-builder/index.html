Export

Load an LDT photometric file to enable export.
Why IFC? Native Revit .rvt/.rfa is a closed binary format that can only be written by Revit itself. IFC is the open BIM standard every major tool — including Revit — imports, and it carries the geometry plus electrical/lighting property sets. In Revit: Insert → Link IFC (or Open → IFC).

Add a product, drop its datasheet + 3D model + LDT, then move straight on to the next — the part code and description are read from the datasheet automatically. When you're done, export every IFC in one ZIP.
